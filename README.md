# EYFI Campus Ambassador — Reward Ladder Prototype

Interactive reward ladder built for the Polygnan SDE assessment.

## Files
- `reward-ladder.html` — the interactive prototype (open directly in any browser, no build step needed)
- `EXPLANATION.md` — tools/approach writeup for submission
- `demo.mp4` — screen recording of the interaction (add this before submitting)

## How to view
Just open `reward-ladder.html` in a browser, or enable GitHub Pages on this repo (Settings → Pages → deploy from main branch) to get a shareable live link.
