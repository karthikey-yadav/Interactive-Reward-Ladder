# EYFI Reward Ladder — Approach

Built an interactive reward ladder prototype using plain HTML/CSS/JS. A draggable slider simulates an ambassador's live registration count; each milestone node unlocks with a pop animation and the vertical progress line fills accordingly, giving ambassadors a game-like sense of climbing toward the next reward. Quick-jump buttons let a reviewer preview each milestone instantly without dragging.

**Tools used:** HTML/CSS/JS (no framework, single file, fully self-contained), Claude for debugging.
